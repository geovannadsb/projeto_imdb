## Sobre o Projeto

Este projeto foi desenvolvido como atividade prática da disciplina de **Business Intelligence II**, com o objetivo de aplicar conceitos de:

- ETL com Power Query
- Modelagem de dados
- Criação de medidas com DAX
- Desenvolvimento de dashboard interativo no Power BI

A base de dados contém informações sobre filmes, como orçamento, receita, gênero, diretor, avaliação IMDb e Oscars.

---

## Perguntas de Negócio

O dashboard foi desenvolvido para responder às seguintes perguntas:

- A indústria cinematográfica teve lucro ou prejuízo?
- Quais diretores geram mais receita?
- Quais gêneros são mais lucrativos?
- Quais filmes tiveram maior faturamento?
- Como a quantidade de filmes evoluiu ao longo dos anos?
- Qual a proporção de filmes com avaliação excelente e comum?
- Como os filmes estão distribuídos por gênero?

---

## Indicadores do Dashboard

- Total de Oscars
- Média de Avaliação IMDb
- Retorno Financeiro Total

---

## Visualizações

O dashboard possui os seguintes gráficos:

- Receita Bruta por Diretor
- Top Filmes por Receita
- Receita Bruta por Gênero
- Filmes por Ano
- Status de Crítica (Excelente x Comum)
- Distribuição de Filmes por Gênero

---

## Insights Obtidos

- A receita está concentrada em poucos diretores.
- Alguns filmes concentram grande parte do faturamento.
- A maior parte dos filmes possui avaliação classificada como "Comum".
- Alguns gêneros são mais lucrativos que outros.
- A quantidade de filmes aumentou ao longo dos anos.
- Nem todos os filmes com alta receita geram lucro.
